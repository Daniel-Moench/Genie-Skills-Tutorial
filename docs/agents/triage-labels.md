# Triage labels

The skills use five canonical triage roles. This table maps them to this repository's labels.

| Role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue. |
| `needs-info` | `needs-info` | Waiting on the reporter for more information. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be actioned. |

Use the tracker label when a skill mentions its role. Edit the tracker label column if the vocabulary changes.

## Additional labels

| Tracker label | Meaning |
| --- | --- |
| `needs-grilling` | Maintainer wants a grilling session before implementation. |
| `resolved` | Ticket is done; apply this label and close the ticket. |
