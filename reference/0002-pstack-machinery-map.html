pstack machinery map

Every pstack behavior, traced to its file and its switch. Compressed from lesson 0002.

Artifacts

~\.copilot\
├── settings.json                  "pstack@pstack-claude": true   ← enable flag (ALL of pstack)
├── pstack-models.md               role → model sheet             ← only file setup-pstack wrote
└── installed-plugins\pstack-claude\pstack\
    ├── skills\                    ~70 skills
    ├── agents\                    pstack:poteto-agent, pstack:comment-sicko…
    ├── models.json                legal roles + efforts (validates the sheet)
    └── hooks\
        ├── copilot-hooks.json     hook registration
        ├── session-start.ps1/.sh  assembles the injected block
        ├── session-start-context.md       the mandate text
        ├── session-start-copilot.md       Copilot translation rules
        ├── session-start-copilot-sheet.md preamble for valid-sheet role lines
        └── session-start-copilot-setup.md fallback: "run setup-pstack"

Hook flow (every session start)

SessionStart (matcher: startup|resume|clear|compact)
  session-start.ps1 copilot          # .sh on Unix
    + session-start-context.md       # mandate
    + session-start-copilot.md       # Copilot notes
    + sheet valid against models.json?
        yes → session-start-copilot-sheet.md + checked role lines
        no  → session-start-copilot-setup.md
  → printed → injected as the EXTREMELY_IMPORTANT block

PreToolUse (matcher: view|task|bash)
  Windows: "exit 0"                  # no-op
  Unix:    pre-tool-use.sh           # real check, 5s timeout

Sheet syntax

<role>: <model-id | inherit-parent | auto>[, more…][ @<effort>]
default effort: <session | level>

inherit-parent / auto  → task() omits model      (subagent = session model)
model-id               → task(model: "model-id")
invalid sheet          → no role lines injected; setup fallback instead

Skills that dispatch on role models: architect, arena, how, interrogate, no-comments, poteto-mode, reflect, swarm, thermos, why.

Mandate scope

poteto-mode fires when ANY of:
  multi-file change, or signature change other files call
  design / architecture choice
  bug with unknown cause, or perf issue
otherwise: work directly

precedence: user instructions > mandate
  (CLAUDE.md, AGENTS.md, direct requests,
   ~\.copilot\copilot-instructions.md, .github\copilot-instructions.md)

Switches

GoalSwitch
Remove everything (mandate + skills + agents) settings.json → "pstack@pstack-claude": false
Stop mandate, keep skills (native) session hook: off in ~\.copilot\pstack-models.md
Mute router, keep skills invocable Override line in ~\.copilot\copilot-instructions.md
Pin models per role Edit ~\.copilot\pstack-models.md or rerun setup-pstack
