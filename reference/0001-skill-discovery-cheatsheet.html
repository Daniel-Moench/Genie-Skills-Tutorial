Wiring files

FileHolds

~\.copilot\settings.jsonPlugin enable flags, e.g. "pstack@pstack-claude": true

Loading model

  • Always in prompt: name + description of (most) skills — the index.
  • On invocation only: SKILL.md body + linked extra files.
  • Large plugins: partial index; unlisted skills still load by exact name.

Invocation paths

  1. Slash command — user-explicit: /teach
  2. Description match — model-automatic; description = trigger surface
  3. Named by another skill — e.g. poteto-mode → tdd
