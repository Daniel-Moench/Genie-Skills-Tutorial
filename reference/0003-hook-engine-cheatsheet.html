Why awk

Requirement: run on any Unix with zero installed dependencies.
POSIX guarantees exactly two scripting languages: sh and awk.
json.awk           JSON parser for the event piped in on stdin
copilot-context.awk Unix twin of session-start.ps1 (assembles the block)
pre-tool-use.awk    tool-gate verdicts
script-contracts.awk allowlisted scripts + legal argument shapes

Session-start outcomes

no sheet        → mandate + notes + setup text
sheet valid     → mandate + notes + preamble + role lines (rebuilt, never quoted)
sheet invalid   → mandate + notes + problem list + setup text
fires only on:    startup | resume | clear | compact
                  (sheet edits need a fresh/resumed session)

PreToolUse verdicts (Unix only)

view  inside plugin folder                    → allow
bash  one of 7 scripts, matching contract     → allow
task  pstack:* agent, model not in sheet      → deny
anything else                                 → silent (normal permission flow)

Windows: "exit 0" — a failing hook can block tools, sh+awk not guaranteed,
so a no-op stub is the only safe port. Costs: more permission prompts,
sheet enforcement is advisory only.
